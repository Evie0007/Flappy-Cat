# Flappy Cat

A Flappy Bird-style game starring a donut cat, originally built for my CS 36A: Programming with Java course.

## 🎮 Play in your browser

**[Play Flappy Cat →](https://evie0007.github.io/Flappy-Cat/)**

Press **Space** to flap. Avoid the pipes. Try to beat your high score.

## Repo structure

```
Flappy-Cat/
├── docs/    # Web version (HTML5 Canvas + JS) — deployed via GitHub Pages
└── java/    # Original Java Swing desktop version
```

## Running the Java version locally

Requires a JDK.

```bash
cd java
javac *.java
java App
```

## Built with

- **Web version:** HTML5 Canvas, vanilla JavaScript
- **Desktop version:** Java, Swing
